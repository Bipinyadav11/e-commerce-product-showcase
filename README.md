# 🛍️ ShopEase - E-Commerce Product Showcase

A modern and responsive e-commerce website built using **React.js, Vite and Tailwind CSS**.

ShopEase provides a smooth online shopping experience with product browsing, search, category filtering, product details, shopping cart and checkout functionality.

## ⚙️ Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Go to the project directory:

```bash
cd YOUR_PROJECT_FOLDER
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal.

## 🛒 Main Functionality

### Product Browsing

Users can browse a large collection of products from different categories.

### Search

Users can search for products using the search bar.

### Category Filter

Products can be filtered by categories such as:

- Electronics
- Fashion
- Home
- Sports
- Fitness
- Accessories
- Furniture
- Appliances
- Outdoor

### Shopping Cart

Users can:

- Add products
- Increase quantity
- Decrease quantity
- Remove products
- View total price

### Checkout

Users can enter their customer information and place an order through the checkout interface.

After successful checkout, an order confirmation message is displayed.
